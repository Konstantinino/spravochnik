# Справочник

Windows-приложение — корпоративный справочник ответов по отделам (техподдержка, юристы, менеджеры, СПП, шаблоны).

Данные изначально лежат в JSON в корне этой папки. Приложение (`app/`) при первом запуске копирует их в `%AppData%\spravochnik\Spravochnik\` и дальше работает уже с этой копией.

## Что умеет

- Выбор отдела в шапке
- Список тем слева (с папками), ответ справа в Markdown
- Поиск по текущему отделу
- Кнопка «Добавить» — новая тема в выбранный отдел, можно вставить фото в середину текста

## Установка на ПК (для сотрудников)

1. Возьмите файл `app/release/Spravochnik-Setup-1.0.0.exe`
2. Запустите установщик, пройдите шаги мастера
3. Откройте «Spravochnik» с рабочего стола или из меню «Пуск»

Node.js и терминал **не нужны**.

> Уже установленное приложение хранит свои данные в AppData. Переустановка программы **не затирает** добавленные темы, если не удалять папку данных вручную.

## Структура проекта

```
справочник/
  guide.json              ← данные: техподдержка
  guide_lawyers.json      ← юристы
  guide_managers.json     ← менеджеры
  guide_spp.json          ← СПП
  templates.json          ← шаблоны ответов
  info.txt                ← описание формата данных
  app/                    ← код Windows-приложения
    electron/             ← главное окно, сохранение файлов
    src/                  ← интерфейс (React)
    resources/data/       ← копия JSON, которая попадает в установщик
    release/              ← готовый Setup.exe (после сборки)
```

## Как вносить изменения

Есть **два разных вида правок** — от этого зависит, нужно ли пересобирать установщик.

### 1. Правки только данных (темы / ответы в JSON)

Если нужно поправить или добавить текст **в исходных файлах** (`guide.json` и т.д.) до раздачи новой версии:

1. Отредактируйте нужный JSON в корне (или в `app/resources/data/` — держите их синхронно)
2. **Пересоберите установщик** (см. ниже), чтобы новые сотрудники получили обновлённые данные при первой установке

Если правка нужна **только на уже установленном ПК**:

- откройте приложение и добавьте тему кнопкой «Добавить», **или**
- отредактируйте JSON в `%AppData%\spravochnik\Spravochnik\`  
  Пересобирать установщик **не нужно**.

### 2. Правки программы (интерфейс, поиск, кнопки, логика)

1. Установите [Node.js LTS](https://nodejs.org/) (один раз)
2. В терминале:

```bash
cd app
npm install
npm run electron:dev
```

3. Меняйте код в `app/src/` (интерфейс) или `app/electron/` (файлы, окно)
4. Проверяйте в открывшемся окне приложения
5. Когда всё готово — **пересоберите установщик** и раздайте новый `.exe`

### Нужно ли пересобирать установщик?

| Что изменили | Пересборка Setup.exe |
|---|---|
| Код приложения (`app/src`, `app/electron`) | **Да** — иначе у сотрудников останется старая программа |
| Seed-данные в `app/resources/data/` для новых установок | **Да** |
| Данные только в AppData на конкретном ПК | **Нет** |
| README / комментарии | **Нет** |

Добавление тем через кнопку «Добавить» в уже установленном приложении установщик **не требует**.

## Сборка установщика

Из папки `app`:

```bash
cd app
npm install
npm run dist:ascii
```

Готовый файл появится здесь:

`app/release/Spravochnik-Setup-1.0.0.exe`

`dist:ascii` собирает через путь без кириллицы (`C:\spravochnik-build\...`), потому что обычный NSIS-сборщик ломается на путях вроде `Desktop\справочник`.

Альтернатива (если проект лежит в пути только из латиницы):

```bash
npm run dist
```

### Быстрая проверка без установщика

```bash
cd app
npm run pack
```

Запуск: `app/release/win-unpacked/Spravochnik.exe`

## Данные и медиа

- Формат записей: `id`, `question`, `answer`, опционально `parent_id`, `has_children`, `photos`, `documents`
- Новые фото при добавлении через приложение сохраняются в `%AppData%\spravochnik\Spravochnik\media\` и вставляются в Markdown как `![](media/....jpg)`
- Старые Telegram `file_id` в JSON **не открываются** в десктопе (нужна отдельная миграция)
