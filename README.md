# REST INFO

Windows-приложение — корпоративный справочник ответов по отделам (техподдержка, юристы, менеджеры, СПП, шаблоны) с ролями пользователей и синхронизацией через Яндекс.Диск.

## Установка на ПК

1. Скопируйте `app/release/REST-INFO-Setup-1.1.0.exe`
2. Установите как обычную программу
3. На рабочем столе появится ярлык **REST INFO**

Node.js и терминал на рабочем ПК не нужны.

## Первый вход

1. Откройте приложение → **Регистрация**
2. Нужны: имя, почта, пароль, подтверждение пароля  
   Пароль по умолчанию скрыт, можно нажать «Показать»
3. Зарегистрироваться можно **только с почтой из белого списка**

Учётная запись с почтой **`kostya.alone18@yandex.ru`** при регистрации автоматически становится **админом** (эта почта уже в whitelist).

### Роли

| Роль | Права |
|---|---|
| Читатель (`user`) | Только просмотр |
| Редактор (`editor`) | Добавление и изменение тем, отправка на Диск |
| Админ (`admin`) | Всё выше + настройки пользователей, whitelist, токен Диска |

## Интерфейс

- Слева от выбора отдела — **статус синхронизации** простыми словами («Актуально», «Синхронизация…», «Есть локальные изменения»…)
- **Добавить** — только у редактора и админа
- Круглая стрелка рядом — появляется после локальных изменений, отправляет данные на Яндекс.Диск; после успешной отправки пропадает
- Иконка шестерёнки (только админ) — настройки
- Иконка пользователя — имя, почта, выход

## Синхронизация (Яндекс.Диск)

- Папка на Диске: **`REST INFO`**
- Админ указывает OAuth-токен в настройках
- После запуска локальные данные сразу доступны; в фоне идёт подтягивание с Диска
- Редактор/админ после правок нажимает кнопку со стрелкой, чтобы отправить изменения

Токен можно получить в кабинете Яндекс OAuth для приложения с доступом к Диску.

## Как вносить изменения в код/данные

### Правки в уже установленном приложении

- Читатель — только смотрит
- Редактор/админ — «Добавить» / «Изменить», затем кнопка отправки на Диск  
  Пересборка установщика **не нужна**

### Правки программы (этот репозиторий)

```bash
cd app
npm install
npm run electron:dev
```

После изменений кода **пересоберите установщик** и раздайте новый `.exe`.

| Что изменили | Нужен новый Setup.exe? |
|---|---|
| Код (`app/src`, `app/electron`) | Да |
| Seed JSON в `app/resources/data/` для новых ПК | Да |
| Темы через UI + отправка на Диск | Нет |
| README | Нет |

### Сборка установщика

Из‑за кириллицы в пути проекта используйте:

```bash
cd app
npm run dist:ascii
```

Файл: `app/release/REST-INFO-Setup-1.1.0.exe`

## Структура

```
README.md
guide*.json / templates.json   ← исходные данные (seed)
app/
  electron/                    ← окно, auth, Яндекс.Диск
  src/                         ← интерфейс
  resources/data/              ← данные внутри установщика
  release/                     ← Setup.exe (не в git)
```

Локальные данные пользователя: `%AppData%\rest-info\REST-INFO\`
