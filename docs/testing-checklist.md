# Чеклист тестирования REST INFO v2

> Статус выполнения: см. [PROJECT-STATUS.md](PROJECT-STATUS.md). Полный E2E на production — **после deploy**.

## Сервер

- [ ] `docker compose up -d --build` — контейнеры стартуют
- [ ] `curl http://localhost:3000/health` → `{"ok":true}`
- [ ] `POST /auth/register` с whitelist email → JWT
- [ ] Владелец (`owner`) может выдать роль `admin` другому пользователю
- [ ] Админ **не** может менять/удалять владельца
- [ ] Удаление владельца требует `successorId` (передача владения)
- [ ] `POST /auth/login` → JWT
- [ ] `GET /departments/support/topics` → список тем
- [ ] `POST /departments/support/topics` → создание
- [ ] `PUT /departments/:dept/topics/:id` с неверным If-Match → 409
- [ ] `GET /sync/changes?full=true` → полный snapshot
- [ ] `node dist/import-from-json.js <data-dir>` — импорт с Диска

## Клиент — онлайн

- [ ] Указать URL сервера → вход → full sync
- [ ] После переустановки/обновления Setup URL сервера подставляется сам (из `%AppData%`)
- [ ] Чтение тем без сети (после sync) — оффлайн
- [ ] Создание темы — сразу на сервере
- [ ] Редактирование — lock на сервере, unlock при выходе
- [ ] Два редактора одну тему — второй получает «занята»
- [ ] Темы и подтемы в списке слева — по алфавиту
- [ ] В режиме правки: ⋮ → «Скопировать ссылку» → вставить в другую тему (или на выделенный текст) → переход + «← Назад»
- [ ] В тексте ответа: `+` → список тем у курсора → выбор; пробел после `+` закрывает список до нового `+`
- [ ] «Вставить файл» (до 10 МБ) → в тексте карточка с именем; открыть / скачать; файл >10 МБ — ошибка
- [ ] Настройки: владелец выдаёт роль «Админ»; админ не видит «Изменить/Удалить» у владельца
- [ ] Владелец: внизу настроек «Место на сервере» — итог и разбивка текст/фото/файлы по отделам; админ блок не видит
- [ ] Удаление владельца: обязательно выбрать нового владельца

## Клиент — оффлайн

- [ ] Отключить сеть → редактировать тему → «Сохранено локально»
- [ ] Кнопка «Синхронизировать» → очередь уходит на сервер

## Конфликты

- [ ] Изменить тему оффлайн + изменить на сервере → sync → модалка + сравнение рядом

## Обновления

- [ ] nginx `client_max_body_size` ≥ 120M (иначе upload Setup → 413)
- [ ] `POST /admin/releases` + Setup в `/data/updates/` (или `upload-release.js` после деплоя лимита)
- [ ] Клиент показывает «Обновить» при новой версии

## Legacy

- [ ] `STORAGE_BACKEND=yandex` — старая синхронизация через Диск
